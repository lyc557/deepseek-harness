七、以后遇到 Electron unavailable，按照这个流程排查

我建议你以后直接把下面当成 DSH Browser 故障排查 SOP。

Step 1：确认 DSH Web 本身是否启动

看到：

dsh web: http://127.0.0.1:3080/...

说明：

DSH Web ✅

不要把 Web 启动问题和 Browser 问题混在一起。

Step 2：确认 Browser Plugin
dsh plugin --profile web list

或者源码环境：

pnpm dsh plugin --profile web list

确认：

dsh-builtin-browser

存在。

Step 3：找实际 Electron

不要直接猜版本。

执行：

cd ~/.dsh/profiles/web

readlink -f node_modules/electron

例如这次得到：

.../electron@44.1.0/node_modules/electron

这个版本才是我们应该检查的。

Step 4：检查 Binary

根据实际版本：

ls -l node_modules/.pnpm/electron@44.1.0/node_modules/electron/dist/Electron.app/Contents/MacOS/Electron

如果：

No such file or directory

基本就可以判断：

Electron package 在，但 Runtime Binary 没下载。

Step 5：直接运行 Binary
node_modules/.pnpm/electron@44.1.0/node_modules/electron/dist/Electron.app/Contents/MacOS/Electron --version

如果得到：

v44.1.0

说明 Electron 本身正常。

Step 6：Binary 不存在就运行 install.js
node node_modules/.pnpm/electron@44.1.0/node_modules/electron/install.js

然后重新检查：

node_modules/.pnpm/electron@44.1.0/node_modules/electron/dist/Electron.app/Contents/MacOS/Electron --version
八、以后看到这几个现象，可以快速判断
现象	大概率原因
dsh web 都启动不了	DSH / Profile / credentials 问题
dsh web 启动，但 electron unavailable	Browser/Electron 问题
electron 目录不存在	Electron package 没安装
electron 目录存在，但 dist/Electron.app 不存在	Electron Runtime 没下载
Electron --version 能运行	Electron 本身正常
pnpm add 显示 downloaded 0	pnpm package 已缓存，不代表 Electron Binary 一定存在
有多个 electron@版本	一定要先确认 DSH 实际解析的是哪个版本
version must be a string	credentials schema / DSH 版本不匹配
全局 DSH + 源码 DSH 混用	很容易出现 profile/schema/plugin 版本冲突
九、你现在这台 Mac mini 的正确状态
